Inline feedback inside a form or panel — there is no toast system in this product.

```jsx
<Alert tone="danger" icon={<AlertCircle size={16} />}>
  That email or password isn&rsquo;t right. Try again.
</Alert>
```

Copy is a plain sentence in the brand's voice, never an error code. Success messages replace the form rather than sitting above it (see the Contact "Thanks — we've got it." state).
